# budgetany.github.io

The BudgetAny web page: <https://budgetany.github.io/>, with one page per category:
[BudgetPix](https://budgetany.github.io/budgetpix/), [Budget3D](https://budgetany.github.io/budget3d/) and
[BudgetLatent](https://budgetany.github.io/budgetlatent/).

Plain HTML and one stylesheet (`assets/site.css`), no build step. The BudgetPix page's budget demo reads
`budgetpix/demo/manifest.json` and the images next to it; the BudgetLatent page's viewer reads
`budgetlatent/viewer/viewer.json` and the WebP sprites next to it (its editing, reference and layout-box examples
are in `budgetlatent/refs/`), and the Budget3D page's viewer the files in `budget3d/viewer/`.
